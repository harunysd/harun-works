## Built with

- [Nuxt.js](https://v3.nuxtjs.org) - Core application framework
- [GSAP](https://greensock.com/gsap/) - Smooth transitions and animations
- [OGL](https://github.com/oframe/ogl) - Background WebGL canvas
- [LocomotiveScroll](https://github.com/locomotivemtl/locomotive-scroll) - Smooth scrolling

---

## Usage

1. Clone this repo:
   ```shell
   $ git clone https://github.com/harun-works/portfolio
   ```

2. Install dependencies:
   ```shell
   $ yarn
   ```
   or
   ```shell
   $ npm install
   ```

3. Run the local server:
   ```shell
   $ yarn dev
   ```
   or
   ```shell
   $ npm run dev
   ```
